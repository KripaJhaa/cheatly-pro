Detailed steps

  1. Open the Cheatly-*.dmg file from your email.
  2. Drag Cheatly.app into the Applications folder.
  3. Open Applications, then Control-click Cheatly and choose Open.
  4. Choose Open again if macOS asks you to confirm.

If macOS still blocks it

Open Terminal and run this once after copying Cheatly to Applications:

xattr -dr com.apple.quarantine "/Applications/Cheatly.app"
open -a "/Applications/Cheatly.app"

This is needed because the current DMG is unsigned. A signed and notarized build will not require this step.

2. Start using Cheatly

  1. Cheatly stays in the macOS menu bar.
  2. Click the Cheatly menu-bar icon to show or hide the terminal.
  3. Keep the Mac online so trial or subscription access can be verified.

Shortcuts

  • ⌘ N — show or hide the terminal overlay
  • ⌘ M — switch between terminal interaction and click-through mode
  • Drag the header — move the overlay
  • Drag the bottom-right corner — resize the overlay
  • ⌘ C / ⌘ V — copy and paste in the terminal

Having trouble?

Check that you are on macOS 13 or newer, that the app was copied to Applications, and that your Mac is online. For help, join the Cheatly Discord community →
